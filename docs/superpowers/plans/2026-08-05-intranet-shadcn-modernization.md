# Intranet Admin Panel — shadcn/ui Modernization Implementation Plan

> **For agentic workers:** This plan is executed by the Codex subagent (`codex:codex-rescue`), handed off phase-by-phase via `SendMessage`/task prompts from the orchestrating session — NOT via `superpowers:subagent-driven-development` or `superpowers:executing-plans`. Each task below is self-contained enough to paste directly into a Codex task prompt. Visual verification after each task is done by the orchestrator using the Browser tool (Codex has no browser access), not by Codex itself.

**Goal:** Replace native HTML controls (`<select>`, `<table>`, hand-rolled modal `<div>`s) in the intranet admin panel with shadcn/ui components, using only the project's existing color palette, without changing any business logic.

**Architecture:** Install shadcn/ui into `intranet/`, map its theme CSS variables to the existing Tailwind brand colors, generate the needed primitives into `intranet/components/ui/`, then swap native elements for those primitives page by page — starting with `usuarios` as the pilot, then rolling the same primitives out to `produtos` and `solicitacoes` (the only other pages with native controls; `dashboard` and `administrativo` are placeholder pages with no native controls and are out of scope).

**Tech Stack:** Next.js 15, React 19, TypeScript, Tailwind CSS 3, shadcn/ui (Radix UI primitives, generated as local code — no closed dependency), lucide-react (already in use, shadcn uses it too).

## Global Constraints

- No new colors: only `graphite`, `charcoal`, `ice`, `lime`, `coral`, `amber`, `soda`, `muted` (from `intranet/tailwind.config.ts`) may be used anywhere, including shadcn theme tokens.
- No business logic changes: all Supabase queries, filter predicates, handlers (`loadProfiles`, `createProfile`, `deleteProduct`, `transitionRequest`, etc.) keep their exact current behavior.
- No dark mode work.
- Do not touch `agenda`, `deb`, `gbb`, `marketing`, `bbb360-adm` pages, or any API routes, or RLS/migrations.
- Density: compact/corporate — control heights `h-9`/`h-10` (not the current `h-11`), table cell padding `py-2.5 px-3` (not the current `py-4 px-4`).
- Every task ends with `npm run build --prefix intranet` passing with zero errors.
- Do not commit. The orchestrator reviews and commits after each task is verified.
